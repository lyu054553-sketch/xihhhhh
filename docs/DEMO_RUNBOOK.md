# 货不压钱 · v0.3 五分钟演示

演示使用虚构零食数据，金额为成本占用或预计采购承诺，不代表银行余额或真实收益。当前真实 v0.3 后端未完成联调，必须在“契约夹具演示”和“真实 API 联调演示”之间明确标注，不能把测试响应说成模型输出。

## 演示前

1. 对照 [API Contract v0.3](API_CONTRACT.md) 和[本次验证记录](VALIDATION_RESULT.md)。
2. 执行 `python sample-data/generate.py --check` 核对输入包。
3. 无 API 时运行 `start.ps1`：只演示输入与数据页，运行按钮应明确报 `API_NOT_CONFIGURED`。
4. 魏提供真实服务后，使用 `start.ps1 -ApiBase <完整地址/api/v1>`。后端先加载合成数据，不调用旧导入或重置接口。
5. 本次自动录屏使用 Playwright 契约夹具；画面常驻“非真实后端 / 非模型调用”。不连接真实业务数据。

## 五分钟时间线

下表是目标联调讲解顺序。在真实服务交付前，配合带夹具标记的录像讲解界面行为；现场直接运行未配置 API 的页面时，不会出现计算结果。

| 时间 | 操作 | 解说重点 |
| --- | --- | --- |
| 0:00–0:30 | 展示品牌与数据页 | 通用连锁零售接口，虚构零食案例；版本与输入包可核对 |
| 0:30–1:10 | 滞销诊断：滨江店、每日坚果、14 天窗口 | 区分实际零销量和缺失销量；库存金额按成本计，原因需证据 |
| 1:10–1:50 | 跨店调拨：滨江店至文二路店、海苔脆片 | 查看后端建议数量及调拨前后库存；内部调拨不等于全链路现金释放 |
| 1:50–2:20 | 近效期：文二路店香辣豆干批次 | 查看到期日、预测窗口、预计销量和成本风险敞口；不说确定报损 |
| 2:20–2:50 | 采购刹车：城西店 PO-003 | 调整的是可取消的未到货采购量；整箱约束仅按已声明假设 |
| 2:50–4:10 | 资金周转模拟：先整理情景，再确认计算 | 预览只有调整与假设，不出现结果金额；确认后展示基线/方案和缺货风险 |
| 4:10–4:35 | 对结果建议进行模拟确认 | 服务返回 `recorded/simulation` 才算记录成功；不修改真实单据 |
| 4:35–5:00 | 展示缺项、失败、修改输入失效 | 错误不替换成成功数据；下一步是真实后端和模型验收 |

资金周转模拟示例问题：

> 城西店每日坚果的 PO-003 少采购 6 袋，看看库存资金占用、预计采购支出和缺货风险。

该段是用户输入示例，不是预设回答。实际 `scenario_id`、调整、金额、风险、步骤与证据只能来自本次返回。若 30 天没有后续补货，基线与减购方案都可能缺货，不应把减少采购承诺描述为无代价收益。

## 异常演示

| 场景 | 如何演示 | 预期 |
| --- | --- | --- |
| 无 API 配置 | 正常启动但不传 `ApiBase`，运行分析 | 503 `API_NOT_CONFIGURED`，无结果卡 |
| 数据范围为空 | 契约夹具返回 `no_data` | 空状态，不填充预期文件 |
| 缺必需数据 | 返回 `needs_input`、缺项和补充问题 | 提示补充，旧结果失效 |
| 上游模型失败 | 夹具注入 `AI_TIMEOUT/AI_UNAVAILABLE` | 明确故障注入；不声称已测真实模型 |
| 非法响应 | 夹具返回不合法 JSON、字段或关联版本 | 阻止使用响应并显示错误 |
| 预览后修改参数 | 修改门店、日期或自然语言描述 | 旧情景不能继续确认，需要重新整理 |
| 快速切换/取消等待 | 延迟夹具响应后切换 Agent 或取消 | 页面保持正确上下文，不声称已撤销后端运行 |
| 移动端 | 390 像素宽运行上述界面 | 导航、状态、表单和确认可用；表格在自身容器滚动 |

## 答辩口径

**哪些已实现？** 五个入口的统一请求、响应校验、表单、状态、证据、情景确认、模拟决策，以及合成数据、测试和演示材料。具体边界见[朱的交付清单](ZHU_DELIVERY.md)。

**是真实大模型完成的吗？** 当前没有这项验收结论。视频中的步骤和结果由标注的测试夹具提供；魏的真实模型、工具和接口还需正式联调。

**确认会改变采购单吗？** 不会。情景确认只启动计算，建议确认只记录模拟决策。v0.3 不执行真实业务操作。

**省下多少钱？** 只能解释本次模拟的成本占用或预计避免采购承诺，不能说银行余额增加、真实回款或客户 ROI。前端不自行计算这些数字。

**为什么不能直接接原后端？** 原后端没有 v0.3 两条统一路由，数据域和生命周期也不同。需要魏按唯一契约实现，不能用旧工作台或前端常量伪装兼容。
