## 与上次交付的变化

上次 13c467e 及之前的 v0.3 前端契约验证保留在 Git 历史。本轮按魏实际实现切换到 v1.2，不在旧统一接口上增加兼容补丁。

- 原 /agent-runs 和模拟决策接口被当前零售、工作台、方案和任务 API 取代。
- 金额改为元，比例为0—100；不再使用分金额、统一运行状态或虚构的情景会话字段。
- 合成包跟随实际后端种子；旧三店四商品输入不再作为当前服务依据。
- 浏览器主流程访问本地实际后端，旧契约夹具录像不再作为本轮证据。
- 保留请求错误、页面隔离、人工确认、合成声明和来源展示的公共机制。
