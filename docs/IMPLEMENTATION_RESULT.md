- B1 口径与纯计算：完成。金额字段、现金事件、证据等级、缺失与异常分母均有代码和测试。

- B5 联调交付：完成本地服务联调、数据库迁移、样例、自动测试和本文档同步。

## 未完成项与真实性边界

- **真实 ERP Connector：** 未完成，当前只支持本地合成快照和 API 边界。
- **真实模型凭证 / LangGraph：** 未配置、未调用；当前 Agent 解释由结构化规则驱动，不能宣称模型已运行。
- **PostgreSQL、对象存储、队列：** 未在本轮启用，SQLite 仅作为本地持久化实现。
- **完整 OR-Tools 最优求解：** 环境未安装 OR-Tools；当前情景模拟返回确定性候选组合，并明确标记 `feasible_advice`，不宣称最优。
- **真实现金回款、发货、收货、改价、停采、群发：** 均未执行；外部状态未知时页面显示未知。
- **完整导入向导与文件导出：** 本轮提供可重复样例和执行草稿状态，尚未实现正式 Excel 导入/单据文件导出。
