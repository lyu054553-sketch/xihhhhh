# v0.3 前端结构与交互

以 [API Contract](API_CONTRACT.md) 为输入输出依据。原生 HTML、CSS 和 ES modules 共用请求、校验和渲染，五个 Agent 的差异集中在表单配置。

## 模块

| 文件 | 职责 |
| --- | --- |
| index.html、styles.css | 页面骨架、响应式导航、共用样式和可访问标签 |
| app.js | 每个 Agent 独立的输入、运行与决策状态；渲染已校验的响应 |
| assets/js/agent-config.mjs | 五类表单字段、示例问题和请求参数转换 |
| assets/js/api-client.mjs | JSON 请求、超时、取消和结构化错误；写请求不自动重试 |
| assets/js/agent-contract.mjs | 请求/响应关联、状态、证据及单位校验，整数分显示 |
| assets/js/request-state.mjs | 请求序号和失效控制 |
| assets/js/dataset.mjs | 合成输入清单与下载路径校验 |
| scripts/serve_frontend.py | 静态页面与两个 POST 路由的透明转发，不含业务计算或数据库 |

导航只有五个 Agent 和数据说明。当前契约未定义的导入、审批、ERP 执行及在线重置入口不提供。

## 运行流程

输入范围与参数 → POST agent-runs → 校验编号、版本、单位和结构 → 按六种状态呈现结果。

- succeeded / partial：指标、证据、建议与告警。
- needs_input：补充输入。
- no_data：无数据说明。
- failed：错误及人工恢复。
- awaiting_confirmation：情景卡；人工确认相同情景后再次发起模拟。
- 建议的模拟确认或模拟拒绝：等待 decisions 返回 recorded + simulation。

接口同步执行。等待时只显示请求处理中，返回后才展示服务提供的 steps。HTTP 200 的 failed 与 HTTP 错误分别呈现；无效 JSON、版本或编号错配、金额格式错误都不进入结果区。

切换页面不会把慢响应渲染到其他入口；同一入口运行期间禁止重复提交。取消等待不撤销服务端运行，完成与否未知时保留请求编号供核对。

输入变化立即清空旧结果、情景和决策入口。资金模拟复用 session_id；数据版本、规则版本或日期改变则建立新会话。确认时原样提交 scenario_id、周期、调整项和假设，前端不补算业务数值。

## 数字、证据与决策

- _fen 验证为安全整数后精确显示人民币元；未知显示“未知”，实际零显示零。
- 指标保留服务提供的单位；比例以 0～1 输入显示百分比。
- 证据包含来源、记录号、字段、值和业务时点，建议引用已有证据。
- 资金模拟展示库存资金占用、采购承诺与缺货风险；调拨和采购减量不被描述为到账现金或客户收益。
- 确认与拒绝只记录模拟 decisions；等待或已记录时锁定同一建议，错配响应不能显示成功。

## 数据、演示与布局

筛选项来自带版本的合成输入清单，下载不表示已加载到后端。生产页面不读取 reference 或 tests/fixtures 来生成结果，接口失败不切换演示数据。

浏览器隔离测试可使用夹具验证前端，其录屏明确标注为契约夹具演示。真实后端、模型调用与自然语言准确率需独立验收，见 [验证记录](VALIDATION_RESULT.md)。

桌面固定侧栏，窄屏可关闭导航；表单、提示和证据支持键盘操作。优先展示结果、假设和风险，请求 JSON 放在可展开的复现信息中。
