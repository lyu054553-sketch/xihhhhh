# v1.2 前端结构与交互

当前协议以根目录 [API_CONTRACT.md](../API_CONTRACT.md) 和实际 OpenAPI 为准。原生 HTML、CSS 与 ES modules 统一请求、响应验证、状态和渲染；业务计算只调用魏的后端。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| index.html、styles.css | 页面骨架、响应式导航、表单和状态样式 |
| app.js | 路由、每页状态、输入编辑、预览确认、方案操作和响应渲染 |
| assets/js/api-client.mjs | 超时、取消、HTTP 错误、JSON 请求；写请求不自动重试 |
| assets/js/retail-contract.mjs | 当前响应及关联字段验证、元金额格式化、模拟请求构造 |
| assets/js/retail-view.mjs | 转义、指标、详情、表单与状态标签 |
| assets/js/feedback-review.mjs | 原文核对表单、显式人工判断、日期与确认内容校验 |
| assets/js/workflow-view.mjs | 待评估事项、业务计算摘要、实际方案进度；不计算业务结果 |
| assets/js/proposal-export.mjs | 已保存版本与依据关联校验、CSV/JSON交接资料；不访问接口或写业务数据 |
| assets/js/dataset.mjs | 校验合成输入清单与可下载路径 |
| scripts/serve_frontend.py | 静态公开范围与当前 API 的透明代理 |
| scripts/run_local.py | 启动本地后端和前端，管理本次进程及仓库外数据库路径 |
| backend/ | 魏的确定性业务计算、持久化、版本与 HTTP 接口 |

生产页面不读取 reference 或测试响应作为结果；合成输入包页面只提供来源与下载。金额单位为元，不再采用整数分换算。

## 页面和数据

经营总览读取 retail/overview；风险详情读取 risks/{id}；三个工作台读取 workbenches/{module}，只编辑服务允许的字段。今日待办组合 proposals、execution-tasks 和 work-items。采购模拟先读取 simulation-options 获取真实门店与品类选项，再发送已确认的 retail/simulate 请求。

每页保留独立输入、读取序号和提交状态。离开页面不撤销已经提交的写请求；迟到的读取响应不能覆盖更新的读取。单个浏览器内的业务写操作串行进行，提交期间允许浏览其他页面、暂时禁用业务编辑，防止保存中切换商品或重复操作。操作结束后按当前页面重新呈现失效的数据；改变范围读取失败时不继续展示旧范围指标。超时或断网提示先刷新核对当前记录，避免盲目重复提交。独立的读取请求保持并发，此机制不替代后端事务或跨用户并发控制。

## 工作台与审批

输入变化 → 标记旧测算失效 → 后端计算 → 核对 calculation.valid/errors → 保存 → 提交 → 人工审批 → 生成待执行任务。

展示和按钮以服务返回的方案状态及当前版本为准。审批与生成任务携带 Idempotency-Key，避免同一操作重复创建记录。前端检查回执的方案及版本关联，但无法补足服务端事务与并发控制。

只在前端编辑或 calculate 尚未 save 时，后端旧方案的失效规则仍有缺口；不能把前端按钮禁用视为服务端已解决。详情见[对接清单](FRONTEND_INTEGRATION.md)。

保存有效版本后可下载 CSV/JSON。导出与审批共用最新方案核对入口，顺序读取方案和工作台，比较版本、状态及未保存输入；CSV含UTF-8 BOM、引号转义及公式前缀防护，JSON保留支持字段的原值和null。缺少完整input/calculation/basis的旧种子方案不能导出，需重新计算保存。文件是导出时点的执行准备资料，不是ERP模板、自动执行凭据或完整API原件；服务端原子版本检查仍待魏完善。

## 反馈与模拟

反馈先保存原文，再展示业务核对表单：逐条更正、采信、排除或保留待核实情况，填写现况、处理情况、日期范围及证据来源。未核实内容默认unknown；采信观察不自动变成因果判断。修改核对字段后必须重新勾选，原文修改后先重新保存，不能确认旧草稿。确认内容只使用v1.2已有字段，额外返回字段仅供查看。

反馈会话以risk_id隔离，切换商品不会带入其他门店原文；返回同一商品可继续核查。会话仅在当前页面内存保存，不写入浏览器持久存储。页面刷新后的反馈历史恢复需要魏提供查询接口，不能把当前内存缓存当成服务端历史。

采购模拟明确填写周期、减量百分比、门店及品类。预览在前端形成待确认参数卡，没有结果金额；确认后才调用确定性模拟。修改任一输入会撤销预览和旧结果。备注文字不自动改变结构化参数。

completed 展示基线、方案、差额、分周采购支出与缺货风险；unavailable 保留缺项和空结果。分周曲线不是银行余额，也不能将减少采购当作已回款。

## 展示与可访问性

来源、合成标记、快照与缺项伴随相关结果显示。null 保留未知，0 保留零；商品单位不混用。移动端导航支持关闭遮罩、Escape 与展开状态，表单有标签，加载和错误有明确提示。
